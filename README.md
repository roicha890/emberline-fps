# EMBERLINE

A round-based tactical FPS on three.js — map "Kiln Yard", two teams of five (you + 4 ember bots vs 5 frost bots), bomb plant/defuse on site A, buy menu (SMG / RIFLE / SNIPER / frag), rounds with money economy and loss-streak bonuses, fixed-step 60 Hz simulation, bots with waypoint routes and an advance/hold/engage/plant/defuse state machine. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

Run it: `node serve.ts`, then open http://localhost:8080 (any static file server over `game/` works; no build step, no network requests).
